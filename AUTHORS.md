## Reconocimientos Especiales

### Proyecto Original
Este proyecto está basado en el excelente trabajo de **Hyprnote** por el equipo de FastREPL:
- Repositorio original: https://github.com/fastrepl/hyprnote
- Agradecemos su contribución al ecosistema de software libre

### Comunidad Open Source
Agradecemos a todos los proyectos de código abierto que hacen posible Teramot Note Taker:
- **Tauri** - Framework de aplicaciones desktop
- **Whisper** - Modelo de transcripción de OpenAI
- **React** - Biblioteca de interfaces de usuario
- **Rust** - Lenguaje de programación para el backend

## Cómo Aparecer en Esta Lista

### Para Nuevos Contribuidores
1. Haz tu primera contribución (código, documentación, traducción, etc.)
2. Crea un Pull Request
3. Una vez aprobado, serás agregado automáticamente a esta lista

### Información Requerida
Al hacer tu primera contribución, incluye opcionalmente:
- Tu nombre real o pseudónimo preferido
- Tu perfil de GitHub
- Una breve descripción de tu rol o especialidad
- Tu ubicación (opcional)
